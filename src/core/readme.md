# 图像在空域与频域转换

- image2fd_by_fft() / fd2image_by_fft()

## 目的

- 把图片从空域转换到频域，作为频域图片存储，可以使用频域图片再次还原原图，允许画质损失

## 要求

- 时域转换为频域图片，以像素图片存储信息
- 时域图片与频域图片分辨率保持一致
- 频域图片可能被用户缩放，所以要抗缩放，尽可能在缩放后还原保持质量
- 频域图片可能被 JPEG 编码，所以要抗再编码，尽可能在转化为 JPEG 后还原后保持质量
- 再次编码和缩放都是用户用其他工具实现的，不是受控的

## image2fd_by_dcts 设计（推荐）

全局 DCT-II + 半径布局 + 冗余宏单元 + 备用位置 + 平方根压缩：

1. **全局 DCT-II**：整图二维 DCT 得到实系数频域，没有复数相位（相位对 JPEG 噪声极其
   敏感，FFT/DHT 方案做不到），天然抗再编码。
2. **半径布局**：系数按"归一化频率半径"排序后从中心向外铺满同分辨率像素图，低频在
   中心、高频在边缘。半径排序是尺度不变的：用户对频域图做普通图像缩放后，目标网格
   像素的半径秩 ≈ 源网格对应位置的半径秩（秩 ∝ 面积），逆变换仍能得到频率正确的
   下采样图。
3. **冗余宏单元**：低频系数放入中央 2×2 同值块（中心 6×6 覆盖 0.3x 缩放约 3.3 像素
   的采样间隙），保证任意缩放都能采样到原值；被宏单元吞并的等级（单元内非首个像素）
   系数搬到半径序末尾的"备用位置"，1x 逆变换近乎无损。
4. **平方根压缩编码**：p = 128 + sign·127·sqrt(|c|/M)，量化误差 ∝ sqrt(|c|/M)·M 随系数
   幅值自然衰减（μ 律对数压缩的绝对误差恒为 ~0.27%·M，累加 N 个系数后噪声与 √N 成
   正比，图像越大质量越差），频域图平滑、JPEG 友好。
5. **角部锚点块**：左上角 8×8 常数块存放各通道幅值锚点，逆变换从角落 2×2 平均恢复，
   抗缩放抗 JPEG；颜色走 YCbCr，Y 系数放在 FD 图 G 通道（JPEG 色度抽样污染最小）。

### 实测质量（820×558 UI / 1080×1920 插件）

| 场景                    | UI PSNR | 插件 PSNR |
| ----------------------- | ------- | --------- |
| 1x 逆变换               | 33.0 dB | 28.9 dB   |
| fd 缩放 0.8x 后逆变换   | 12.3 dB | 11.2 dB   |
| fd 缩放 0.5x 后逆变换   | 12.2 dB | 10.6 dB   |
| fd 缩放 0.3x 后逆变换   | 12.4 dB | 11.3 dB   |
| fd 经 JPEG q95 后逆变换 | 15.1 dB | 13.5 dB   |

（缩放为普通双线性图像缩放；0.5x/0.3x 的 PSNR 以同尺寸双线性下采样原图为参照，
亮度与低频结构保持，细节有损属于"允许的画质损失"范围。）

实现 src/core/test/benchmarkFn.ts
针对一对特定算法：如 image2fd_by_fft() / fd2image_by_fft()，把 sample 中图片进行测试

生成通过算法比较原图与还原图（缩放后还原图、jpeg 后还原图）的 psnr 值等指标。形成测试报告

用途：

- agent 在工作时，可以通过 benchmarkFn 评估实现的效果和正确性
- 用户之后可以通过编写 test 引用 benchmarkFn 来进行测试
